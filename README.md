## Features

- **Dashboard** — Real-time project overview with stats across all modules
- **Engineering** — Technical drawing management with folder hierarchy, versioning, and revision tracking
- **Documents** — Project document library with categories, upload, and access control
- **Operasional Lapangan** — Field work tracking per mandor, tower, and floor with live progress updates
- **Material & Gudang** — Inventory management with stock tracking and material request approval workflow
- **Absensi** — Attendance check-in/out with GPS geo-fencing and face photo verification
- **Safety K3** — HSE incident reporting with severity classification and document attachment
- **Komunikasi** — Real-time team chat with direct messages, group, and broadcast support
- **AI Features** — AI-powered field monitoring with detection feed and false-positive management
- **Laporan** — Reports and analytics across all modules with PDF export
- **Master Data** — Admin panel for managing users, towers, workers, vendors, equipment, and shifts

## Installation

1. Download the latest `.apk` from [Releases](https://github.com/twintower-systems/TwinClick-App/releases)
2. On your device: **Settings → Security → Allow install from unknown sources**
3. Open the file and tap **Install**

> Requires Android 5.0 or higher
