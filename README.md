## Features

- **Project Management** — track tasks, milestones, and progress
- **Engineering Drawings** — upload, version, and manage technical drawings
- **Document Management** — centralized document storage with access control
- **Attendance (Absensi)** — geo-fencing & face photo verification
- **Real-time Chat** — team communication via WebSocket
- **AI Assistant** — intelligent project insights
- **Reports & Analytics** — dashboards and exportable reports

## Installation

1. Download the latest `.apk` from the [Releases](https://github.com/twintower-systems/TwinClick-App/releases) page
2. On your Android device, go to **Settings → Security → Install unknown apps** and allow installation
3. Open the downloaded file and tap **Install**
4. Launch **TwinClick** from your home screen

> Minimum requirement: Android 5.0 (Lollipop) or higher
